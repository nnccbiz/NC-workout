# מערכת שליטה להבטחת בטיחות מזון

מערכת בקרה לחומרי גלם במפעל מזון, לפי תוכנית בטיחות המזון: מהגדרת חומר הגלם ועד להכנסתו
לייצור או לשיווק ללקוח.

הפעלה: פתיחת `index.html` בדפדפן. אין צורך בהתקנה או בשרת — קובץ HTML יחיד, וכל הנתונים
נשמרים מקומית בדפדפן (localStorage). ניתן לייצא ולייבא גיבוי JSON ממסך "הגדרות וגיבוי".

## זרימת הבקרה

| שלב | מסך | מה נאכף |
|---|---|---|
| 1. הגדרת חומר גלם | מפרטי חומרי גלם | מפרט מאושר: קטגוריה, תנאי אחסון וטווח טמפרטורה, חיי מדף, אלרגנים, סיכונים ואמצעי בקרה (כולל CCP), מסמכים נדרשים ובדיקות מעבדה |
| 2. רכישה לפי מפרט | ספקים · רכש | הזמנה נפתחת רק לספק מאושר בעל תעודות בתוקף, ומקובעת לגרסת המפרט |
| 3. קבלה במחסן | קבלה במחסן | רשימת בדיקות מול המפרט; כשל בבדיקה קריטית פוסל את המשלוח ופותח אי-התאמה |
| 4. בדיקה טרם שימוש | אצוות ובדיקה | כל משלוח נכנס להסגר; שחרור מותנה במעבר כל הבדיקות ובתוצאת מעבדה תקינה כשנדרשת |
| 5. הכנסה לייצור / שיווק | שחרור לייצור/שיווק | הנפקה רק מאצווה משוחררת ובתוקף, כנגד אסמכתה (אצוות ייצור או לקוח ומשלוח) |

## כללי בקרה הנאכפים במערכת

- אין רכש ללא מפרט מאושר, ואין רכש מספק מושעה / בהערכה / בעל תעודה שפגה (ניתן לכיבוי בהגדרות).
- חריגת טמפרטורה מטווח המפרט נקבעת אוטומטית מהמדידה בשדה ופוסלת את המשלוח.
- חיי מדף שנותרו מתחת למינימום שבמפרט — פותחים אי-התאמה; מוצר פג תוקף אינו נקלט.
- אצווה בהסגר אינה זמינה לייצור או לשיווק; אצווה פגת תוקף אינה ניתנת לשחרור או להנפקה.
- כל חריגה פותחת אי-התאמה עם פעולה מתקנת (CAPA), הנסגרת בתיעוד שם ותאריך.
- כל הנפקה מחייבת אסמכתה — בסיס לעקיבות דו-כיוונית ולהחזרה מהשוק.

## מסכים נוספים

- **לוח בקרה** — מדדי בקרה, התראות פעילות (תפוגה, הסגר, תעודות ספק, אי-התאמות, הזמנות באיחור).
- **אי-התאמות** — יומן חריגות ופעולות מתקנות, אוטומטיות וידניות.
- **עקיבות** — שרשרת מלאה לפי אצווה פנימית, אצוות ספק, אצוות ייצור או שם לקוח:
  מפרט ← הזמנת רכש ← קבלה ← בדיקה טרם שימוש ← הנפקה ← אי-התאמות קשורות.

המערכת נטענת עם נתוני דמו לצורך התרשמות; "מחיקת כל הנתונים" במסך ההגדרות מתחילה מערכת ריקה.
